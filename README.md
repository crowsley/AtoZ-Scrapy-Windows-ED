## 📌 About AtoZ Scrapy Windows ED

**AtoZ Scrapy Windows ED 0.0.1** is an enterprise-grade, high-concurrency web scraping framework and native Windows desktop application. Forked from Scrapy, it combines an asynchronous **Windows IOCP Event Loop Engine**, **Playwright Dynamic JS Rendering**, **Real-Time Data Streaming**, **Multi-Format Exporters**, **Keyword/Phrase Filtering**, **Scraping Limits Controls**, and a **Built-In GitHub Release Auto-Updater**.

## 🌟 Key Features

1. **🖥️ Native Windows Desktop GUI Window**
   - Dark modern Windows 11 interface (`AtoZ-Scrapy-Windows-11-ED.exe`).
   - High-contrast inputs and real-time execution logs.

2. **🌐 Universal Multi-Site Web Scraper (`universal`)**
   - Automatically extracts clean text, headlines, paragraphs, and links from **ANY website URL** (Wikipedia, News sites, Blogs, Forums, E-commerce).
   - Built-in template presets: `universal`, `reddit`, `wikipedia`, `news`, `demo_quotes`.

3. **🔍 Keyword & Phrase Filtering System**
   - Target specific topics or phrases (e.g. `LLM, AI, app ideas`).
   - Engine filters out noise and extracts only matching content.

4. **📊 Live Data Feed & Multi-Format Exporters**
   - Stream scraped items in real-time to a dark-themed Treeview table.
   - One-click export options: **CSV**, **JSON**, **TXT**, and **PDF** directly to `C:\Users\saghi\Downloads`.

5. **⏱️ Scraping Limits Controls**
   - **Max Items Limit (`CLOSESPIDER_ITEMCOUNT`)**: Stop engine automatically after N items.
   - **Max Depth Limit (`DEPTH_LIMIT`)**: Cap page crawl depth.

6. **🛠️ Full Scrapy Core Feature Matrix**
   - Visual controls for **AutoThrottle**, **Download Delays**, **HTTP Response Cache**, **Retries & Timeouts**, **User-Agent Header**, and **Robots.txt compliance**.

7. **✨ AI Spider Generator**
   - Turn any target URL into a dedicated `.py` spider module in 1 click.

8. **🔄 GitHub Release Auto-Updater**
   - Automatically checks GitHub releases and updates the local app with 1 click.
